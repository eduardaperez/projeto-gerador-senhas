# 🔐 Projeto Gerador de Senhas

Aplicação front-end para criação de senhas fortes e personalizadas, desenvolvida com HTML, CSS e JavaScript, com foco em usabilidade e boas práticas de segurança.

## 🚀 Funcionalidades

* Geração de senhas seguras automaticamente
* Personalização do tamanho da senha
* Inclusão de letras maiúsculas, minúsculas, números e símbolos
* Interface simples, intuitiva e responsiva
* Copiar senha gerada com um clique

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)

## 📦 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/eduardaperez/projeto-gerador-senhas.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd projeto-gerador-senhas
   ```

3. Abra o arquivo `index.html` no navegador.

Pronto! O projeto estará funcionando localmente.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido como parte do aprendizado em desenvolvimento web, com o objetivo de praticar:

* Manipulação do DOM
* Lógica de geração aleatória em JavaScript
* Estruturação de layout com CSS
* Boas práticas básicas de segurança para senhas
